## Features

1. A single global playlist where you can add songs from your local filesystem.
2. A clean simple interface with a focus on just getting the vibes going.
3. Support for common audio formats (MP3, WAV, OGG, FLAC).
4. Has basic playlist controls: shuffle & looping (individual track or full playlist).

## Building & Using

Halcyon is supported for Windows, MacOS (untested), and Linux. 

```shell
# Clone the repository
git clone https://github.com/exoad/halcyon
cd halcyon
# Install dependencies
flutter pub get
# Run the app
flutter run
```
